# Arduino Interfacing — University of California

## What is this course about?

This course introduced the basics of using Arduino with electronic components. It covered how a program can read inputs from components and use those inputs to control outputs.

## Why I took this course

My interest in robotics started at a school workshop in Class 8, where a teacher introduced Arduino. After that, I tried small robotics projects at home. I could follow examples, but I wanted to understand why the code made the components work, so I took this course to learn the basics properly.

## What I learned

- Arduino basics
- Digital inputs and outputs
- Sensors and electronic components
- Reading input signals
- Controlling output devices
- Basic hardware interfacing
- Connecting program logic with hardware

## How it helped me

It helped me connect the programming side with the physical components. When Arduino reads a sensor or controls an output, I have a better idea of what the code is doing.

I have used these ideas in my Arduino security and monitoring project, which combines a keypad, LCD, temperature and humidity sensor, ultrasonic sensor, LEDs, and a buzzer.

## Where I use these skills

I use these basics in Arduino and embedded-systems projects. They are also a starting point for learning more about sensors, microcontrollers, and automation.
