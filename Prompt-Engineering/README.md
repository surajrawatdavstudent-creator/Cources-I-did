# Advanced Prompt Engineering — Vanderbilt University

## What is this?

This course is about writing better prompts and using AI tools in a more effective way.

**Completed:** October 2026

## Why did I learn this?

I wanted to improve my prompt writing because I was not good at explaining what I actually wanted from an AI tool. Many times, I knew what information I needed, but I could not write the prompt properly or give enough useful details.

This course helped me understand how to write clear and well-structured prompts. After learning this, I was able to get information in a much more precise and detailed way, with the important points properly covered.

## What I learned

- How to write clear and effective prompts
- How to give proper instructions and context
- How to include the details needed for a better answer
- How to improve a prompt when the first result is not good enough
- How to use prompting for research, learning, and problem solving

## How I use it

I use prompt engineering as a supporting skill in my studies and technical projects. It is especially useful when I need to research a new topic or understand something that I have not worked with before.

For example, while researching my robotics projects, I can write a detailed prompt to find out:

- What components I will need
- How the components should work together
- What steps I should follow
- What problems I may face
- What a practical roadmap for the project could look like

This helps me get useful information in a more organised way instead of asking very general questions.

## What this skill means to me

Prompt engineering is not a replacement for learning or doing the work myself. I use it to ask better questions, understand technical topics faster, research ideas, and plan projects more clearly.
