# Python — University of Michigan

## What is this course about?

This course covered the basics of Python programming and common programming concepts used to write simple programs.

## Why I needed this course

Python is useful for programming, data handling, and automation. Since I am working on programming and robotics projects, I needed a practical understanding of Python before using it for larger tasks.

## What I learned

- Variables and data types
- Conditions and loops
- Functions
- Lists and other common data structures
- Basic program structure
- Writing and testing simple Python programs

## How it helped me

The course helped me understand how Python programs are structured and how different programming concepts work together. It also gave me a base for writing small programs instead of only learning syntax separately.

## Where I use these skills

I use Python for programming practice and plan to use it for data handling and automation in electronics and robotics projects. I also use it when working on small programming tools and project-related tasks.
