# Python — University of Michigan

## What is this course about?

This course covered the fundamentals of Python programming and the basic concepts used to write simple programs.

## Why I took this course

When I started exploring programming for robotics and electronics, I did not want to rely only on code copied from examples. I wanted to understand the building blocks well enough to read a program, change it, and write small parts myself. I took this course to get that foundation in Python.

## What I learned

- Variables and data types
- Conditions and loops
- Functions
- Lists and other common data structures
- Basic program structure
- Writing and testing simple Python programs

## How it helped me

It gave me a starting point for understanding and writing simple Python programs. I keep strengthening these skills through practice, and I want to apply Python to logging and analysing data from future electronics projects.

## Where I use these skills

I use Python for programming practice and small coding tasks. One direction I want to explore next is using it with electronics projects to collect, organise, and analyse sensor readings.
