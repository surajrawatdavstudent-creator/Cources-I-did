## What Each Folder Contains

Each course folder has:

- A short README
- What the course is about
- Why I took it
- What I learned
- How I use or plan to use the skill
- The course certificate

## Why I Keep This Repository

I do not want this to be only a collection of certificates. The certificates show that I completed the courses, while my projects show how I use the skills.

## What I Want to Show

My main goal is to show a clear link between learning and projects:

**Course → Skill → Project → Practical use**
