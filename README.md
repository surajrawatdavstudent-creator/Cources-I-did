## What each folder contains

Each course folder has:
- A README explaining the course, why I took it, what I learned, and how I use or plan to use those skills
- The course certificate as a PDF

## Why I keep this repository

I want to keep my course records organised and explain how each course fits into my learning. The certificates show course completion; my projects show how I practise the skills.

## Opening certificates

The links above open the PDF files directly instead of using GitHub's file-preview page. Depending on your browser, a PDF may open in a tab or download first. If it downloads, open the downloaded PDF to view it.
